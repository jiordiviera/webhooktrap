Observation for the PO / A01 (not a classification): the 419 comes from Laravel's CSRF middleware. The route is in the `web` group and `bootstrap/app.php` exempts only `saml/*/acs` from CSRF, so with the repository's default configuration every Stripe delivery would be rejected before the handler runs. The harness did not edit the app to get past it, because a run on an edited app would not be on the production path (15.4). The spec has no finding type for "every valid delivery rejected at D1", so this repository contributes **0 findings** to H1 although the handler is broken for real deliveries. See the pilot report on whether ONCE-4 should stay "not a finding" for the proxy study.
